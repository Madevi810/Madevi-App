# Riset: Tutorial & Problem Solve (19 Okt 2026)

## 15+ Sumber Dianalisis

### 1. iFixit (ifixit.com)
**AMATI**: Panduan perbaikan berlangkah dengan foto tiap langkah, tingkat kesulitan, estimasi waktu, alat yang dibutuhkan.
**TIRU**: Format masalah → alat → langkah → risiko. Estimasi waktu & kesulitan.
**MODIFIKASI**: Foto diganti ilustrasi SVG/diagram prosedural.
**Keputusan**: ✅ Diadopsi (format panduan perbaikan)

### 2. wikiHow (wikihow.com)
**AMATI**: Artikel "cara" dengan langkah bernomor, gambar tiap langkah, tips & peringatan terpisah.
**TIRU**: Bagian "Peringatan" dan "Tips" terpisah dari langkah utama.
**MODIFIKASI**: Format baku Madevi sudah ada (masalah→penjelasan→persiapan→cara→risiko→penyelesaian); tambah "tips".
**Keputusan**: ✅ Diadopsi (struktur langkah)

### 3. Instructables (instructables.com)
**AMATI**: Proyek DIY komunitas, kontes, komentar per langkah.
**TIRU**: Komentar per langkah (terhubung ke Line).
**MODIFIKASI**: Tanpa kontes berhadiah (simulasi).
**Keputusan**: ✅ Diadopsi sebagian

### 4. Stack Overflow
**AMATI**: Format Q&A, jawaban terbaik ditandai, voting.
**TIRU**: "Penyelesaian terverifikasi" untuk tiap masalah.
**MODIFIKASI**: Aturan #11: semua masalah WAJIB ada penyelesaian.
**Keputusan**: ✅ Diadopsi (pola Q&A terverifikasi)

### 5. YouTube Tutorial (kanal: Kok Bisa, Corridor Digital)
**AMATI**: Durasi, chapter, deskripsi dengan timestamp.
**TIRU**: Estimasi waktu baca; daftar isi berjangkar.
**MODIFIKASI**: Tanpa video; teks terstruktur.
**Keputusan**: ✅ Diadopsi (daftar isi + estimasi)

### 6. MDN "How-to" Guides
**AMATI**: Panduan tugas spesifik, prasyarat jelas, hasil yang diharapkan.
**TIRU**: Prasyarat eksplisit di awal tiap tutorial.
**MODIFIKASI**: Sudah ada di format baku.
**Keputusan**: ✅ Diadopsi

### 7. DigitalOcean Tutorials
**AMATI**: Langkah dengan perintah yang bisa disalin, hasil yang diharapkan per langkah.
**TIRU**: "Hasil yang diharapkan" per langkah; blok yang bisa disalin.
**MODIFIKASI**: Untuk tutorial non-teknis: checklist per langkah.
**Keputusan**: ✅ Diadopsi (verifikasi per langkah)

### 8. IKEA Assembly Instructions
**AMATI**: Instruksi visual tanpa kata, urutan yang tidak bisa salah.
**TIRU**: Diagram langkah untuk tutorial fisik.
**MODIFIKASI**: Diagram SVG prosedural.
**Keputusan**: ✅ Diadopsi (diagram langkah)

### 9. Rumah123 / Artikel Properti (panduan KPR, renovasi)
**AMATI**: Panduan lokal Indonesia (biaya, regulasi, istilah lokal).
**TIRU**: Konteks Indonesia: harga Rp, regulasi, istilah sehari-hari.
**MODIFIKASI**: Semua tutorial pakai konteks lokal.
**Keputusan**: ✅ Diadopsi (lokalisasi)

### 10. Alodokter (artikel kesehatan)
**AMATI**: Disclaimer medis, bahasa hati-hati, rujukan dokter.
**TIRU**: Disclaimer untuk tutorial kesehatan/hukum/teknis berisiko.
**MODIFIKASI**: Wajib di format baku (bagian risiko).
**Keputusan**: ✅ Diadopsi (standar keamanan konten)

### 11. Hipwee / IDN Times (tutorial gaya hidup)
**AMATI**: Bahasa santai, listicle, relevan anak muda Indonesia.
**TIRU**: Nada bersahabat untuk kategori gaya hidup.
**MODIFIKASI**: Tetap akurat, tidak clickbait.
**Keputusan**: ✅ Diadopsi sebagian (nada)

### 12. Petunjuk Obat (brosur farmasi)
**AMATI**: Dosis, kontraindikasi, "hentikan jika..." — format keselamatan ketat.
**TIRU**: Format "hentikan jika..." untuk tutorial berisiko.
**MODIFIKASI**: Berlaku untuk listrik, kimia, kesehatan.
**Keputusan**: ✅ Diadopsi (protokol keselamatan)

### 13. Manual Book Peralatan (mis. manual kipas angin)
**AMATI**: Troubleshooting table: gejala → penyebab → solusi.
**TIRU**: Tabel "bila bermasalah" di tiap tutorial.
**MODIFIKASI**: Sudah ada di format baku ("bila bermasalah").
**Keputusan**: ✅ Diadopsi

### 14. Reddit r/DIY, r/fixit
**AMATI**: Diskusi masalah nyata, solusi komunitas, foto sebelum/sesudah.
**TIRU**: Galeri "sebelum/sesudah" dari komunitas (via Line).
**MODIFIKASI**: Moderasi ketat (aturan Line).
**Keputusan**: ✅ Diadopsi sebagian

### 15. Layanan Service Center (mis. panduan garansi)
**AMATI**: Kapan harus ke profesional vs DIY; batasan garansi.
**TIRU**: Bagian "kapan panggil profesional".
**MODIFIKASI**: Wajib untuk tutorial perbaikan.
**Keputusan**: ✅ Diadopsi (batas DIY)

### 16. TikTok Tutorial (kreator DIY Indonesia)
**AMATI**: Durasi <60 detik, hook 3 detik, teks overlay.
**TIRU**: Ringkasan 30-detik di awal tiap tutorial ("intisari").
**MODIFIKASI**: Teks, bukan video.
**Keputusan**: ✅ Diadopsi (intisari)

## Fitur Terpilih untuk Tutorial
1. Format baku: masalah→penjelasan→persiapan→cara→risiko→penyelesaian + intisari 30-detik
2. Estimasi waktu + tingkat kesulitan (iFixit)
3. Tabel "bila bermasalah": gejala→penyebab→solusi
4. Bagian "kapan panggil profesional"
5. Protokol "hentikan jika..." untuk yang berisiko
6. Checklist verifikasi per langkah
7. Diagram SVG untuk langkah fisik
8. Konteks lokal Indonesia (Rp, regulasi)
9. Komentar per langkah (terhubung Line)
