# Blueprint Security — Akses, Privasi, dan Safety Konten

## Security aplikasi

Pertahankan auth server-side, role/permission, CSRF, rate limit, validasi input/upload,
protection IDOR, audit log, retensi, handling error, dan privacy. UI tidak boleh menjadi satu-
satunya pengaman. Perubahan security memerlukan threat/risk statement dan negative acceptance
criteria.

## Safety konten

Panduan berisiko wajib dibedakan:

- `GENERAL`: risiko rendah, sumber dan batas tersedia.
- `CONTROLLED`: membutuhkan prasyarat, alat, sumber, review, dan kondisi berhenti.
- `STOP`: tidak memberi prosedur; hanya batas serta rujukan bantuan yang sesuai.

Klasifikasi adalah data/policy publikasi, bukan disclaimer dekoratif. Referensi detail tetap
berada di `../../memory/TAXONOMY-PRACTICAL-GUIDES.md`.
