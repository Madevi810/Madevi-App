# UX-001 — Audit visual statis tujuh ruang

## Scope dan dependency
- Tujuan pengguna: Memastikan UI dari ketujuh ruang utama (Explore, Tutorial, Tools, Services, Shop, Profile, Admin) dapat dilihat dan digunakan tanpa ada overlap elemen, reflow responsif yang patah, kehilangan fokus, di seluruh tiga tema (Light, Dark, Madevi On).
- Batas perubahan: Audit statis dan perbaikan statis pada styling, layout, token. Tidak menambah proses runtime baru kecuali diizinkan Owner.
- Dependency / blueprint terkait: CTRL-5A-001.
- File/kontrak diperkirakan: File TSX/CSS pada komponen utama UI di `Madevi_Off`.

## Acceptance criteria wajib
- [ ] AC-01 — Tidak ada elemen UI yang saling menimpa (overlap control) pada breakpoint yang ditentukan (misalnya <400px, 960px).
- [ ] AC-02 — Reflow responsif bekerja dengan baik, tidak ada teks atau panel yang terpotong.
- [ ] AC-03 — Manajemen fokus berjalan lancar, state `focus-visible` tidak tersembunyi.
- [ ] AC-04 — Tiga tema (Light, Dark, Madevi On) di-render tanpa warna fallback yang salah, kontras teks aman, dan `prefers-reduced-motion` menghentikan animasi di Madevi On.

## Acceptance criteria terukur
| ID | Unit | Metode | Ambang | Hasil |
|---|---:|---|---:|---|
| M-01 | TSX/CSS | Transpile & parse | Lulus tanpa error sintaksis | belum |

## Verifikasi yang diizinkan
- Statis: Parsing TSX, balance cek CSS, review manual terhadap CSS z-index dan layout.
- Runtime (jika Owner mengizinkan): Belum diizinkan.
- Yang sengaja tidak dijalankan dan alasannya: Testing browser, dev server, background process (sesuai arahan Owner pada sesi ini yang melarang runtime tanpa persetujuan eksplisit).

## Risiko dan rollback
- Risiko: Perubahan CSS statis bisa merusak layout di tempat lain.
- Compatibility/migration: N/A.
- Recovery: Revert CSS/TSX yang diubah ke commit sebelumnya.
